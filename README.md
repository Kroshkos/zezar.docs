# Сайт проекта Zezar 🌐

Небольшой статический сайт (без сборки и зависимостей) для размещения
**документации** и **новостных статей** проекта
[Zezar](https://github.com/Kroshkos/Zezar).

## Структура

```
.
├── index.html          # Разметка сайта (три страницы: Главная, Документация, Новости)
├── .meta/
│   └── amvera.json     # Конфиг деплоя на Amvera (статический шаблон)
├── css/
│   └── style.css       # Все стили
└── js/
    ├── content.js      # ✍️ ВЕСЬ КОНТЕНТ: статьи документации и новости
    └── app.js          # Логика SPA-навигации и рендеринга
```

## Запуск локально

Сайт — обычный статический HTML/JS, его можно открыть напрямую в браузере
(файл `index.html`) либо запустить любой локальный сервер, например:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Как добавлять контент

### Новая статья документации — откройте `js/content.js` и добавьте объект в массив `docs`:

```js
{
  id: "my-topic",          // уникальный id (будет частью адреса: #docs/my-topic)
  title: "Моя тема",       // заголовок в боковом меню
  html: `
    <h2>Подзаголовок</h2>
    <p>Текст статьи в любом HTML.</p>
  `
}
```

### Новая новость — добавьте объект в массив `news`:

```js
{
  id: "my-news",           // уникальный id (адрес: #news/my-news)
  title: "Заголовок новости",
  date: "2026-10-26",      // формат ГГГГ-ММ-ДД
  tag: "Релиз",            // метка/категория
  html: `<p>Текст новости в HTML.</p>`
}
```

Новости на главной странице отображаются автоматически (3 последних),
в разделе «Новости» сортировка по дате тоже выполняется сама.

## Публикация на Amvera

Сайт подготовлен к деплою как **статический шаблон**: в репозитории лежит
`.meta/amvera.json` с `templateName: "static"` и `framework: "html"`, поэтому
Amvera определит тип приложения автоматически. Сборка и сервер не нужны —
платформа просто раздаёт файлы из корня (`index.html`).

1. Зайдите на [console.amvera.dev](https://console.amvera.dev) → **Create project** (создать проект).
2. Выберите вариант **«Из GitHub-репозитория»** (через интеграцию с GitHub) и укажите этот репозиторий.
3. Amvera прочитает `.meta/amvera.json` и предложит статический шаблон — подтвердите.
4. Нажмите **Deploy**. Через пару минут сайт будет доступен по адресу вида
   `https://zezar-site.amveraapp.com` (домен виден в карточке проекта; там же можно подключить свой домен).

Обновления: любой `git push` в выбранную ветку триггерит пересборку/ redeploy (настройка автодеплоя — в параметрах проекта на Amvera).

Если при создании проекта Amvera не подхватил конфиг, выберите шаблон
**Static / HTML** вручную — структура файлов уже ему соответствует.

## Публикация на GitHub Pages

1. Создайте репозиторий (например, `zezar-site`) и загрузите туда эти файлы.
2. В настройках репозитория: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
3. Сайт будет доступен по адресу `https://<ваш-логин>.github.io/zezar-site/`.

## Особенности

- Без фреймворков и сборки — работает даже при простом открытии файла в браузере;
- Адаптивная вёрстка (мобильное бургер-меню);
- Навигация через хэши (`#home`, `#docs/<id>`, `#news/<id>`) — ссылки можно расшаривать.

# Сайт проекта Zezar 🌐

Небольшой статический сайт (без сборки и зависимостей) для размещения
**документации** и **новостных статей** проекта
[Zezar](https://github.com/Kroshkos/Zezar).

## Структура

```
.
├── index.html          # Разметка сайта (три страницы: Главная, Документация, Новости)
├── amvera.yaml         # Конфиг деплоя на Amvera Cloud (node/browser = статика на nginx)
├── css/
│   └── style.css       # Все стили
└── js/
    ├── content.js      # ✍️ ВЕСЬ КОНТЕНТ: статьи документации и новости
    └── app.js          # Логика SPA-навигации и рендеринга
```

## Запуск локально

Сайт — обычный статический HTML/JS, его можно открыть напрямую в браузере
(файл `index.html`) либо запустить любой локальный сервер, например:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Как добавлять контент

### Новая статья документации — откройте `js/content.js` и добавьте объект в массив `docs`:

```js
{
  id: "my-topic",          // уникальный id (будет частью адреса: #docs/my-topic)
  title: "Моя тема",       // заголовок в боковом меню
  html: `
    <h2>Подзаголовок</h2>
    <p>Текст статьи в любом HTML.</p>
  `
}
```

### Новая новость — добавьте объект в массив `news`:

```js
{
  id: "my-news",           // уникальный id (адрес: #news/my-news)
  title: "Заголовок новости",
  date: "2026-10-26",      // формат ГГГГ-ММ-ДД
  tag: "Релиз",            // метка/категория
  html: `<p>Текст новости в HTML.</p>`
}
```

Новости на главной странице отображаются автоматически (3 последних),
в разделе «Новости» сортировка по дате тоже выполняется сама.

## Деплой на Amvera Cloud

Сайт подготовлен к деплою согласно официальной документации Amvera
([docs.amvera.ru](https://docs.amvera.ru/index.html)). В корне репозитория
лежит файл конфигурации **`amvera.yaml`** с окружением `node` и toolchain
`browser` — это профиль статических/браузерных приложений: сборка не требуется,
а на этапе запуска Amвера раздаёт файлы через встроенный nginx с поддержкой
SPA-маршрутизации (подробности: [Node.JS Browser](https://docs.amvera.ru/applications/environments/nodejs-browser.html),
[Файл конфигурации](https://docs.amvera.ru/applications/configuration/config-file.html)).

### Способ 1 — привязать GitHub-репозиторий (рекомендуется)

1. Зайдите в личный кабинет [console.amvera.dev](https://console.amvera.dev) → **«Создать проект»** → тип сервиса **«Приложение»**, выберите тарифный план.
2. На этапе «Загрузка данных» перейдите на вкладку **«Репозиторий»** проекта и подключите GitHub ([инструкция](https://docs.amvera.ru/applications/git/webhooks.html)):
   - создайте Personal Access Token в GitHub (**User settings → Developer settings → Personal access tokens**) — он нужен даже для публичных репозиториев;
   - вставьте токен в Amvera, выберите репозиторий `Kroshkos/Zezar-site` (или как вы его назовёте) и ветку (например, `main`).
3. Amvera прочитает `amvera.yaml` из корня репозитория и соберёт проект.
4. После успешной сборки сайт будет доступен по адресу вида `https://<имя-проекта>.amveraapp.com` (домен виден в карточке проекта; там же можно подключить свой домен).
5. Дальше любой `git push` в выбранную ветку автоматически запускает пересборку (вебхук реагирует на событие *push*).

### Способ 2 — загрузить файлы через интерфейс

1. «Создать проект» → «Приложение» → на этапе загрузки данных просто перетащите все файлы проекта (включая `amvera.yaml`) в окно интерфейса.
2. Нажмите «Завершить» — начнётся сборка и запуск.

### Частые проблемы

- Если сборка падает или приложение бесконечно запускается, проверьте раздел [Частые ошибки](https://docs.amvera.ru/general/FAQ/) в документации Amvera;
- время на серверах Amvera — UTC ([справка](https://docs.amvera.ru/general/FAQ/UTC-time.html));
- всё содержимое сайта редактируется в `js/content.js`, после пуша изменений сайт обновится сам.


## Публикация на GitHub Pages

1. Создайте репозиторий (например, `zezar-site`) и загрузите туда эти файлы.
2. В настройках репозитория: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
3. Сайт будет доступен по адресу `https://<ваш-логин>.github.io/zezar-site/`.

## Особенности

- Без фреймворков и сборки — работает даже при простом открытии файла в браузере;
- Адаптивная вёрстка (мобильное бургер-меню);
- Навигация через хэши (`#home`, `#docs/<id>`, `#news/<id>`) — ссылки можно расшаривать.
